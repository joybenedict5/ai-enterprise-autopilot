# ⚡ AI Enterprise Autopilot

A multi-agent AI operations system that autonomously monitors 
enterprise workflows and executes actions using LLM-driven 
decision engines.

## 🚀 Live Demo
Coming soon...

## 🧠 What It Does
- 5 specialized AI agents (HR, Support, Finance, Security, Reporting)
- Real-time event classification and routing
- RAG memory system with company knowledge base
- Autonomous action execution
- Live operations dashboard

## 🛠️ Tech Stack
- **Frontend:** React + Tailwind CSS
- **Backend:** Python FastAPI
- **AI:** Groq API (Llama 3.3)
- **Memory:** ChromaDB + RAG pipeline
- **Deployment:** Vercel + Railway

## ⚙️ Run Locally

### Backend
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000

### Frontend
cd frontend
npm install
npm start
